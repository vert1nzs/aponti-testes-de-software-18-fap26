## 📂 Exercício 3 – Organização do README

### Título do Projeto
Formação APONTI - Qualidade e Testes de Software

### Objetivo
Aprender e aplicar boas práticas de documentação técnica utilizando Markdown e versionamento com Git.

### Tecnologias Utilizadas
Git, GitHub e Markdown.

### Estrutura das Pastas
```text
aponti-testes-de-software-18-fap26/
├── README.md (Principal)
```

### Como Executar o Projeto
1. Clone o repositório na sua máquina local.
2. Abra o terminal na pasta raiz do projeto.
3. Use o comando `git pull origin main` para atualizar os arquivos.

## 🚀 Exercício 10 – Desafio Final
Aqui estão os 5 recursos adicionais do Markdown aplicados para o desafio:

1.  **Texto Riscado:** ~~Este texto está ultrapassado e foi riscado.~~
2.  **Texto Destacado:** Use a tag HTML para deixar um termo <mark>em evolução</mark>.
3.  **HTML dentro do Markdown:** Centralizando um texto usando tags HTML:
    <p align="center">Este texto foi centralizado usando código HTML!</p>

4.  **Detalhes Expansíveis:** Clique abaixo para ver o conteúdo oculto:
    <details>
    <summary>Clique para abrir 🔓</summary>
    Você descobriu as tags details e summary funcionando!
    </details>

5.  **Imagem Clicável:** Clique na imagem do logotipo abaixo para abrir a página oficial do GitHub:
