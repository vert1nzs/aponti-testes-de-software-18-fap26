# 1. O que é teste de Software?
```
R: É o processo de avaliação de um sistema para validar se ele atende aos requisitos solicitados e para garantir a qualidade do projeto final.
```
# 2. Por que Testar é importante para o negócio?
```
R: Para mitigar riscos e garantir a confiabilidade, a segurança e o valor comercial do projeto antes do lançamento.
```
# 3. O que carecteriza um Software com qualidade?
```
R: Confiabilidade, segurança, estabilidade, boa usabilidade e o atendimento pleno às necessidades do usuário.
```
# 4. Qual o papel do QA em um time moderno?
```
R: Atuar de forma proativa para prevenir falhas, otimizar processos e disseminar a cultura de qualidade na equipe.
```
